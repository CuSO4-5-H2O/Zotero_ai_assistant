# 2.0 系列验收记录

验收环境：Windows，Zotero 10.0.6，Python 3.12。日期：2026-10-26。正式修订号见 `VERSION`。

## 本轮修复

1. 文献列表原本只显示前 70 篇，补上分批加载入口。
2. 本地多实例 Cookie 相互覆盖，改为按服务端口隔离，并兼容旧窗口重连。
3. 初始化尚未结束时点击栏目，可能被初始页面覆盖；现在尊重使用者已选择的栏目。
4. 空白安装依赖旧调研目录，改为空目录可启动；实际资源和 Zotero storage 通过本机配置指定。
5. 未登录 ChatGPT 时仍请求其模型列表，产生无关错误和等待；现在跳过未登录服务。
6. Crossref 将补充材料列为论文候选；现在限定论文相关类型，并拒绝把组件及 `.s001` 一类 DOI 当正文。缺失年份不再显示 `None`。
7. PDF 翻译直接写后台，可能让未保存的笔记编辑器停留在旧版本；改为通过浮窗合并草稿后保存，排队状态不再冒充已保存。
8. 工作区助手回答后误称「已保存到当前论文」，改成工作区对话提示。
9. 去掉关键运行路径对 E 盘的依赖；公开包保留空仓库与通用导读。
10. 为原生翻译测试隔离保存操作，防止诊断测试写入真实笔记。
11. 云端新环境验证发现测试夹具的 E 盘目录和 Windows 长短路径依赖，已修正；GitHub Actions 全流程通过。

## 适用范围与未完成的外部能力

- Undermind 原生账号/API 一键连接未实现，使用网页及 DOI 结果导入；Elicit 需要有 API 权限的 Key。
- ChatGPT 订阅登录适配器为实验能力，本轮未重新进行账号登录、所有模型的付费调用或跨账号验收。
- 扫描 PDF 需要外部 OCR。没有权限的出版社全文无法保证获取；此前全文待获取条目不会被错误标为已完成。
- Jasmine/Sci-Hub 未被捆绑，也没有绕过验证码、登录或付费墙的功能。
