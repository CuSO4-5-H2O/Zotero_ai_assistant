# 科研笔记仓库 Zotero 插件
适配 Windows、Zotero 10.0.x，需要配套本地服务。安装说明见项目 README，图文使用说明见 docs/使用说明.md。
安装脚本为当前源码路径生成本机 XPI，单独复制 XPI 不能代替配套应用安装。
不含 API 密钥、个人笔记或 PDF。本机自动更新核对版本、ID、兼容性和 SHA-256。禁用插件不会删除笔记或 Zotero PDF。

2.0.27：内置 OpenAlex/arXiv、多来源 HTML/JSON 解析、LibGen DOI 检索；补取全文与文献入库共用 PDF 校验和逐来源日志。实现及设置见配套应用 docs/PDF获取机制与验收.md。
