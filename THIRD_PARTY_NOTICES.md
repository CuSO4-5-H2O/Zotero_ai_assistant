# Third-party components

Python packages are installed separately using `requirements.txt`; their licenses remain in their distributions.

- markdown-it-py — MIT
- mdit-py-plugins — MIT
- pypdf — BSD-3-Clause
- PyJWT — MIT
- cryptography — Apache-2.0 OR BSD-3-Clause
- KaTeX — MIT; downloaded from the npm registry with pinned version and SHA-512 integrity verification. Its license is saved alongside the downloaded assets.

The application does not include Zotero itself, any model weights, paid API credentials, PDF articles or personal notebook content.
