# Security

Please do not publish credentials, login tokens, private PDFs, notebook exports or `.runtime` contents in issues or pull requests.

To report a vulnerability, use this repository's private security reporting option when available. If it is unavailable, open an issue containing only a brief non-sensitive description and request a private contact channel. Do not include working exploit payloads or user data in a public report.

This application is intended for a trusted local Windows session. It is not a multi-user hosted service. AI-enabled features send necessary task context to the provider selected by the user. Credentials and runtime data are deliberately excluded from the source distribution.
